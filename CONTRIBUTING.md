# Developer Documentation

## Local Compilation

Install [uv](https://docs.astral.sh/uv/) and a [Rust toolchain](https://rustup.rs), then build the extension and install the development environment with:

```console
uv sync --locked
```

The extension is built with [maturin](https://www.maturin.rs), and `uv sync` rebuilds it whenever the Rust sources change.

## Local Testing

To ensure all tests pass, run:

```console
uv run poe check-tests
cargo test --no-default-features
```

Tests that compare output against htslib run only when `bgzip` and `tabix` are on the `PATH`, for example after `brew install htslib` or `sudo apt-get install tabix`.
The VCF comparisons also need htslib 1.23 or newer, whose rules for the end of a VCF record `pybgzf` follows.

## Local Linting and Formatting

To check the format, lint, and types of all the code, and run every test, run:

```console
uv run poe check-all
```

To fix what can be fixed automatically, run:

```console
uv run poe fix-all
```

## Benchmarks

Compare against the standard library's `gzip` and, if installed, `bgzip` and `tabix` with:

```console
uv run python benchmarks/benchmark.py 200
```

## Releasing

Releases are published to PyPI by the [`publish_pybgzf.yml`](.github/workflows/publish_pybgzf.yml) workflow with PyPI Trusted Publishing, so no API token is stored in GitHub.

One-time setup:

1. On PyPI, add a trusted publisher for the project `pybgzf` with owner `clintval`, repository `pybgzf`, workflow `publish_pybgzf.yml`, and environment `pypi`.
2. On GitHub, create the environments `pypi` and `github` in the repository settings, optionally with required reviewers.

To release:

1. Bump the version in both `pyproject.toml` and `Cargo.toml`, run `uv lock`, and merge a pull request titled `chore(release): bump to X.Y.Z` into `main`.
2. Tag the merge commit on `main` and push the tag:

   ```console
   git tag X.Y.Z
   git push origin X.Y.Z
   ```

3. The workflow runs the tests, builds the sdist and wheels for every platform, checks that each wheel installs and imports, publishes to PyPI, and creates a GitHub release with notes generated by git-cliff.
